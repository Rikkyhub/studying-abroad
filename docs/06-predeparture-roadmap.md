# 海外語学留学・周遊の出発前準備ロードマップ（一般向けモデル）

最終調査日：2026-10-17。対象：語学学校への長期滞在と、その後の第三国周遊を予定する人の**一般的な準備例**。個人の支払い・雇用・旅券・予約・提出状況は掲載しない。

> **期限の種類**：「公的要件」は政府公式資料で確認。「学校別締切」は所属学校・紹介会社の個別案内で確認。「推奨目安」はこの資料の実務的な整理であり、法令で決まった期限ではない。

## フィリピンで再確認する公的条件

- 日本の一般旅券所持者は、フィリピン政府の一覧では**初期滞在30日間の査証免除対象**。旅券有効期間、帰国または第三国行き航空券等の条件を入国前に確認する。12週間滞在に必要な延長・就学手続は別途確認する。
- **SSP（Special Study Permit）**：入管の公式サービス案内では、学生ビザに該当しない一定の外国人が申請対象。学校による代行・必要書類・ACRとの関係、改定後の手数料は、学校と当局の最新版を照合する。公式ページの一部費用は**2014年更新**で、2027年適用額とはみなさない。
- **eTravel**：公式サイトは https://etravel.gov.ph 。登録は**無料**。**到着前72時間以内**という政府公式案内に従う。登録・QRの中身を公開しない。

## 日本側の住所・社会保険・海外渡航登録（追加調査：2026-10-17）

**住居の退去と住民票の国外転出は別の判断。** 滞在期間、日本の生活の本拠、自治体の運用によって異なる。以下は一般的な調査用モデルであり、特定の人の届出要否を判定しない。

| いつ（期限の種類） | 準備・必要な確認 | 担当／先行作業 | 費用・変動条件・確認先 |
|---|---|---|---|
| 出発90〜60日前（推奨） | 国外転出届が必要か、住民登録先の自治体に照会 | 本人／滞在期間・日本の生活の本拠・住居退去予定を整理 | 江東区は「おおむね1年以上」が目安で、短期留学は必ずしも届出不要。東久留米市は賃貸等を引き払う場合、1年未満でも届出を案内。**自治体ごとの差を確認** |
| 出発30〜14日前（推奨） | 届出が必要なら、受付開始日・本人確認書類・マイナンバーカードの継続利用を確認 | 本人＋自治体／国外転出要否の判断後 | 江東区の例では出国日の**おおむね14日前〜当日**に受付。全国一律の「14日前締切」ではない。必要書類・手数料は各自治体へ |
| 出発60〜30日前（推奨） | 健康保険・年金・住民税の扱いを雇用/退職/国外転出の条件別に確認 | 本人＋保険者・勤務先・自治体／雇用と住民票の見込みを整理 | 海外居住の日本人で厚生年金等に未加入なら国民年金に任意加入できる場合がある。個別の休職中の資格・負担額は一般制度から推定しない |
| 出発60〜7日前（推奨） | 滞在先・期間ごとに外務省の在留届または「たびレジ」を確認 | 本人／国ごとの滞在先・期間を仮決定 | **3か月以上**海外に住所・一時滞在先を定めて滞在する日本人は在留届の対象。**3か月未満**の短期渡航はたびレジを案内。複数国旅行の総期間だけで一律判定しない |
| 国外転出する場合：出国前（手続条件） | マイナンバーカードの国外継続利用手続を確認 | 本人＋自治体／国外転出届との順序を照合 | 外務省・総務省は出国前の継続利用手続を案内。対象者・窓口・有効状態を確認 |

**依存関係**：滞在計画と日本の生活の本拠 → 自治体での国外転出要否確認 → 保険・年金・税・マイナンバーカードへの影響確認 → 必要な届出。住居の解約や出国日だけで国外転出済みと断定しない。

## 期限を調べる際の運用

1. 新しい期限を見つけたら「公式／学校別／推奨」を分類し、出典URL、確認日、適用年度、対象者、変動条件を記録する。
2. 学校・紹介会社の**個人専用の提出日・支払い・予約情報**は公開GitHubに書かず、非公開の正式書類・Notionで管理する。
3. 当局規定、学校手続、第三国への移動条件は相互に依存する。根拠不明の手続を「完了」や「不要」にしない。
4. 週ごとに「期限超過・7日以内・30日以内・次の依存作業」を確認。進捗不明を未実施と断定しない。
