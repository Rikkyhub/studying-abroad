# 日程プランナー（日数の割り振り）

期間（例：5/3〜6/6）を、どの国・町に何日ずつ使うかを入れて、残り日数を見ながら予定を組む画面です。最初の区間（例：モーリシャス、マダガスカル）を決めると、その後に使える日数が自動で出ます。

入力はこのブラウザに自動で残り、公開されません。案A〜Hは、地図・ルート比較と同じ順序の骨組みです（日数は入っていません。国別の目安は[国の比較表（13か国）](../research/africa-13-countries-comparison.md)を参照）。

## 2. 使い方

- 上の「期間」で開始日と終了日を入れます（初期値は5/3〜6/6。年は2027年）。
- 各行に泊数（その場所に泊まる夜の数）を入れると、到着日と出発日が自動で並びます。移動日を泊数とは別に数えたいときは「移動日」の列に入れます。
- 「確定」にチェックを付けた行は、案を切り替えても残ります。まだ決まっていない場所は「仮」のままにします。
- 一番下に残り日数が出ます。マイナスなら期間に収まっていません。
- 泊数に国別の1日単価（宿泊＋食費）を掛けた概算を、合計と比較表に出します。単価は[5月アフリカ周遊：数量×仮単価の予算表](../research/africa-budget-fermi.md)の仮定で、実売価格ではありません。航空券・入場料・ツアー代・ビザは含みません。表にない国（ケニアなど）は概算から除きます。
- 日程を組んだら、下の「パターンを保存して比べる」で名前を付けて保存します。保存したパターンは経路・使った日数・残り日数・最終日が一覧で並び、いつでも読み込めます（このブラウザの中だけに残ります。最大12個）。
- 国の欄に国名（例：ケニア、ザンビア）を入れると、泊数の下に比較表の「最適日数（推計）」が目安として出ます。推計であり、確定ではありません。
- 日数の目安は、国ごとの最適日数（比較表）を参照。ここに出る数字は計算結果であり、予約や確定した予定ではありません。
