# モデルルート作成

「日本 → 滞在地 → … → 日本」の骨組みを、自分で入力して作る画面です。まず滞在地の名前だけを入れ、時期・日数・移動・メモは決まったものから足していけます。空欄のままでも構いません。

入力はこのブラウザに自動で残ります。「Claudeに送る」を押すと、リポジトリの `triage/` フォルダに `route.json` として保存します（最初の1回だけフォルダを選びます。Chrome・Edge向け）。このフォルダの中身は公開されません。

## 2. 使い方

- 「＋行を追加」で滞在地を増やします。▲▼で順番を入れ替え、×で削除します。
- 先頭の「日本（出発）」と末尾の「日本（帰国）」は固定です。
- 期間を国・町ごとの泊数に割り振って残り日数を見たいときは、[日程プランナー](13-day-planner.md) を使います。
- 費用の自動計算・地図への表示は、ルートの形が固まってから次の段階で足します。
