# 公開データと非公開データの分離

このリポジトリは公開されています。個人の実績と公開向けの調査情報を混ぜないでください。

## 公開可能
- 学校・旅行事業者などの一般料金と条件（公式URL・取得日・適用年・通貨を明記）
- 匿名モデルの予算・行程・費用シミュレーション（本人の実際の支払額とは区別）
- 個人を特定しない観光・交通・語学学校の調査

## 非公開で管理
- 個人の請求・支払い履歴・金融資産・所得・税額
- 個別の契約、雇用先、申請履歴、連絡先、住所、予約識別子
- 他人の情報、非公開資料の本文と限定共有URL
- 複数の情報を組み合わせることで個人が特定できる内容

## PR提出とマージ前の確認
1. CSV、Markdown、生成HTML、Issue、PR本文、画像をすべて確認する。
2. 出典付きの一般料金と、個人の支払い・資産情報を混同しない。
3. 自動検査は補助とし、文脈の目視確認も行う。
4. 情報に疑義があるPRはマージしない。現在の関連課題は #16。
5. 過去のGit履歴・PR差分に残った情報は、通常のコミットでは消えない。履歴変更は別途承認を要する。
