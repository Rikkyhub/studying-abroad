## 集計の原則
- 支出台帳は [`../data/expenses.csv`](../data/expenses.csv)。証憑・見積元URL・確認日・通貨を各行に記録する。
- **予算 / 見積 / 請求 / 支払済み / 現地実費**を区別。実費支払と請求額を二重計上しない。
- 一つの費用が「周遊旅行費」と「交通費」に二重計上されないよう、支出ごとに一意IDを付与する。
- 期間外の費用（出発前の用品購入、帰国後の固定費）も旅の因果で発生したものはカテゴリと日付で明示する。
- 日本円換算が必要なときは**通貨額×レート（JPY/通貨）**、レート日・情報源を記録する。
- 未確認金額を0円と扱わない（空欄のまま残し、総費用は**未完成**と明示）。

## 費用カテゴリー
学校・授業 / 住居・寮 / 航空券 / 長距離交通 / 現地交通 / 食料・外食 / 通信 / ダイビング / 観光 / ビザ・SSP / 保険・医療 / 日本の固定費 / 社会保険・税 / 冬服・装備 / 予備費。

## 計算式（全数値がそろった場合）
- **総見込** = 支払確定済みの対象金額 + まだ払っていない対象の最新見積 + 未計上費目の予備費。
- **今後の支払い見込** = 総見込 − 対象の支払済み。
- **残額見込** = 予算上限 − 総見込。
- 一部しか入力されていない間は「既入力額の小計」と表記し、6か月総額と呼ばない。
