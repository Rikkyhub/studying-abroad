## お金の管理原則（公開用の匿名モデル）

- **目標250万円、上限300万円**は6か月全体の予算目標で、利用実績ではない。
- 公開CSVの金額はすべて**見積**（出典あり）または**未確認**（出典なし・推定）。支払い・実費・資金・残高は扱わない。
- 見積合計は各行を1回だけ加算する（二重計上しない）。「未確認」は別枠で表示し、何からも差し引かない。
- 金額が分からない行は空欄のまま「金額未入力」とし、**0円として扱わない**。
- 複数通貨の元金額を保持し、円換算はレートと基準日を記載する。
- 個人の請求・支払い・資産は公開リポジトリの外で非公開に管理し、ここにはリンクも書かない。
