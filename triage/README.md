# triage/（判断の受け取り場所・非公開）

費用表の「要否」判断を、ページの「Claudeに送る」ボタンがここへ保存します（`cost-triage-<ページ名>.json`）。
Claude（AI）は作業のたびにここを確認し、不要になった行の整理や見積の見直しに使います。

- **中身は Git にコミットしない**（`.gitignore` 済み。この README だけが追跡対象）。個人の判断・メモが入るため。
- 特別に伝えたいことがあるときは、別の場所（非公開Notion等）に書いて、会話で知らせる。
- 判断は保存した時点のスナップショット。表を変えたらもう一度「Claudeに送る」。
