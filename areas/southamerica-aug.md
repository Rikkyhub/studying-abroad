# 8月の周遊（南米）

## 1. 旅の要点

2027年8月に、ケープタウン留学（6〜7月）のあと、日本へ帰国するまでの約3週間で**南米**を巡る案です。8月は、南米と**アフリカ**の2つの方向で比べていて、どちらも決定ではありません。予約・確定はしていません。アフリカの案は [8月の周遊（アフリカ）](africa-aug.md) にあります（上のメニューの「8月」から切り替えられます）。

- **期間**：7/31（土）または8/1（日）にケープタウンを出て、**8/20（金）までに日本着**が基本です（8/23復職予定）。日数は21暦日（8/1発なら20暦日）で、出入国と長距離の移動を含みます。
- **案**：ケープタウンからサンパウロへ飛び、ペルー（マチュピチュ・アマゾン）を中心に回る SA8-1〜SA8-4。
- **イグアス経由の案**：ケープタウンからイグアスの滝へ飛び、ペルーへ向かう SA8-5・SA8-6 も仮に置いています（下の「イグアス経由の案」）。
- **費用**：航空券・現地費・観光費はまだ取得していません（未計上。0円ではありません）。
- 地図は [ルート地図](../maps/route-map.html) の「8月 南米」で見られます。

## 2. 旅の流れ（南米）

ケープタウンから南米へは、**サンパウロ⇄ケープタウン／ヨハネスブルグだけが直行**です（第三者の運航データ。LATAM・SAA）。そのため、どの案もケープタウン→サンパウロ→リマから始まり、日本へは米国などを経由して帰ります（リマ・ラパス・グアヤキルから東京への直行はありません）。日数は21暦日（8/1発なら20暦日）で、出入国と長距離の移動を含みます。

| 案 | ルート | 日数の配分（目安） | 主な未確認 |
|---|---|---|---|
| **SA8-1 ペルー集中** | ケープタウン → サンパウロ → リマ → クスコ → マチュピチュ → クスコ → リマ → イキトス → リマ → （米国経由）東京 | クスコ・マチュピチュ6、イキトス4、移動・予備11 | リマ→東京（直行なし） |
| **SA8-2 ペルー＋ワカチナ** | SA8-1 ＋ リマ → ワカチナ（バス約4〜6時間）→ リマ | クスコ5、イキトス4、ワカチナ2、移動10 | ワカチナのバギーの規制の最新状況 |
| **SA8-3 ペルー＋ウユニ** | ケープタウン → サンパウロ → リマ → イキトス → リマ → クスコ → マチュピチュ → クスコ → ラパス → ウユニ → ラパス → （乗継）東京 | イキトス4、クスコ5、ウユニ3、移動9 | ラパス→東京の通し運賃 |

**8月の季節**：マチュピチュは乾季で**混雑のピーク**（最低3℃）。イキトス（アマゾン）は減水期で、降水は年間で最も少ない。ウユニは乾季で最も寒い（最低−7.6℃）。ガラパゴスは水温18〜23℃で冷たく、マンタ・マンボウに会いやすいが、霧雨（ガルーア）の時期です。

**注意**：南米（ペルー・ボリビア・エクアドル・ブラジル）は黄熱のリスク国です。8月の南米のあとはそのまま日本へ帰るため、南アフリカなどへ入るときの黄熱証明の条件は、8月の帰路には関係しない見込みです（推計。日本の入国条件は未確認）。5月に南米へ行く順番（プランB）では、南米のあと南アフリカに入るため関係します（比較資料の第1章）。

航空券・現地費・観光費は、どの区間もまだ取得していません。比較・日別・出典は [アフリカと南米：5月・8月の順番とルート比較](../research/africa-south-america-2027-comparison.md) の第5章・第11章にあります。

## 3. イグアス経由の案（仮）

ケープタウンから**イグアスの滝**へ飛び、ペルーのマチュピチュ・アマゾン・リマでのダイビングへ向かう2案です。SA8-1〜4 とは別の案で、**どれも仮置きです。予約・購入はしていません**。

| 案 | ルート | 国（観光する国） | 状態 |
|---|---|---|---|
| **SA8-6 イグアス→ウユニ→ペルー**（ウユニあり） | ケープタウン → イグアス（ブラジル側・アルゼンチン側）→ ラパス → ウユニ（2泊3日）→ ラパス → プーノ → クスコ → マチュピチュ → タンボパタ（アマゾン）→ リマ（ダイビング）→ 東京 | ブラジル・アルゼンチン・ボリビア・ペルーの4か国 | 仮 |
| **SA8-5 イグアス→ペルー**（ウユニなし） | ケープタウン → イグアス → クスコ → マチュピチュ → タンボパタ → リマ（ダイビング）→ 東京 | ブラジル・アルゼンチン・ペルーの3か国 | 仮 |

- **必須にしたい体験**：イグアスの滝（ブラジル側・アルゼンチン側の両方）、マチュピチュ、アマゾンの森と川での2〜4泊、ペルーでのファンダイビング（1日・原則2本）。
- **比較したいもの**：ウユニ（あり／なし）、パラグアイ（国境観光。入国条件しだい）、ワカチナのサンドボード（余裕があれば）、安くて珍しい宿。
- **日本着**：8/20（金）着を標準、8/24（火）着を延長として、**別々に検算**します。乗継と時差を含め、日本に着く日が上限を超えないかを便ごとに確かめます。
- **夜行の長距離バスは基本避け**、昼間の移動にします。国数を増やすために、移動や体験を削る案は採りません。
- **マチュピチュ**：8/14（土）を仮の第一候補、8/13・8/15を予備にしています。2027年の販売開始日・入場枠・列車と前泊が分かるまでは、日程は**確定ではありません**。
