# 調査レポートのワークフロー

## 手順
1. 最新mainから `research/<issue>-<slug>` ブランチを作る。`gh pr list` で同Issueの既存PRを確認。
2. 既存の `research/*.md` と `research/sources.md` を読み、重複・矛盾を避ける。
3. 公式情報（政府・学校・事業者の公式サイト）から調べる。非公式は補助と明記。
4. `template.md` の構成で `research/` 配下に書く。
5. 検証コマンドを流し、`studying-abroad-pr` の手順でPRを出す。

## 品質基準
- 各情報に：URL・確認日・適用年度・通貨・対象人数・含まれる内容。
- 確認できないことは「未確認」と書く。推測で埋めない。
- 2026年のイベント・料金を2027年として書かない。
- 末尾に検索ログ（クエリと結果の要点）。
- 本人の支払い・資産・予約番号・勤務先情報は書かない。個人を特定しない一般向け・匿名モデルで書く。
- 予約・問い合わせ送信などはユーザー承認が必要。
